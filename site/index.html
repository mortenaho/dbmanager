میز کار کوئری برای سه موتور پایگاه داده

به SQL Server، PostgreSQL یا MySQL وصل می‌شوید، کوئری را می‌نویسید و با F5 اجرا می‌کنید. ساختار پایگاه، طراحی جدول و نمودار رابطه‌ها در همان پنجره است.

همان کارهایی که داخل برنامه هست

این صفحه معرفی برنامه دسکتاپ است. خود پایگاه داده از مرورگر باز نمی‌شود؛ اتصال روی رایانه شما انجام می‌شود.

ویرایشگر SQL

اجرا، بررسی نحو، قالب‌بندی، پیشنهاد خودکار و قطعهٔ sel و ins و upd و join.

نتایج

انتخاب سلول، کپی با هدر یا بدون هدر، و ذخیره به Excel و JSON.

Object Explorer

جدول، نما، رویه و تابع. کوئری تازه، هزار ردیف اول، و جزئیات شیء.

طراحی جدول

ساخت جدول تازه و ویرایش ستون‌ها، نوع داده و کلید اصلی.

نمودار رابطه

چیدمان جدول‌ها بر اساس پیوندها، با نمایش کاردینالیتی رابطه.

اسکریپت

CREATE، INSERT، CREATE به‌همراه INSERT، اسکریپت اسکیما و پشتیبان پایگاه.

تاریخچه

کوئری‌های قبلی، پیام‌ها و نتیجه، با مدت نگهداری قابل تنظیم.

نوشتن بدون WHERE

دستهٔ UPDATE یا DELETE که شرط WHERE ندارد اجرا نمی‌شود.

پروفایل اتصال

ذخیره سرور، ورود سریع به اتصال‌های اخیر، و ساخت پایگاه تازه.

شروع کار

۱وصل شوید

موتور، میزبان، درگاه و نام کاربری را وارد کنید یا یک پروفایل ذخیره‌شده را باز کنید.

۲کوئری بنویسید

از Object Explorer یک کوئری تازه باز کنید یا هزار ردیف اول یک جدول را ببینید.

۳اجرا کنید

F5 نتیجه را در گرید می‌آورد. خروجی را کپی کنید یا به Excel و JSON ذخیره کنید.

رفتن به انتشارها

رمز اتصال روی رایانه شما می‌ماند. این وب‌سایت فقط معرفی برنامه است و به پایگاه داده وصل نمی‌شود. تاریخچه کوئری را می‌توانید طوری تنظیم کنید که گذرواژه در آن ذخیره نشود.
