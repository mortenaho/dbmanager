History and saved servers

Reopen an earlier query, with its messages and results. Profiles remember the server so the next connection is one click, and you can create a database from the explorer.

Safety

A wide UPDATE never slips through.

An UPDATE or DELETE batch with no WHERE clause is refused. Add the condition, then run it again. Query history keeps the SQL and the output, and leaves passwords out.

UPDATE orders
SET status = 'closed';
