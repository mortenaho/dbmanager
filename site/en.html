What the app actually does

This page introduces the desktop app. It does not open your database in the browser. Connections run on your computer.

SQL editor

Execute, parse, format, autocomplete, and the sel, ins, upd, and join snippets.

Results

Select cells, copy with or without headers, and save as Excel or JSON.

Object Explorer

Tables, views, procedures, and functions. New query, first 1,000 rows, and object details.

Table designer

Create a table and edit columns, data types, and the primary key.

Relationship diagram

Arrange tables from their links and show relationship cardinality.

Scripts

CREATE, INSERT, CREATE and INSERT, schema scripts, and a database backup script.

History

Earlier queries, messages, and results, with a configurable retention window.

Writes without WHERE

An UPDATE or DELETE batch with no WHERE clause is not executed.

Connection profiles

Save a server, reconnect from recent profiles, and create a database.

Start

1Connect

Enter the engine, host, port, and user, or open a saved profile.

2Write a query

Open a new query from Object Explorer, or preview the first 1,000 rows of a table.

3Run it

F5 fills the grid. Copy the cells, or save them as Excel or JSON.
